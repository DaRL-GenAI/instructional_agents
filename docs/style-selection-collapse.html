46 styles in. One style out.

The foundation run picks a course-wide slide theme from a 46-entry inventory. Across the eight completed runs in exp/, six landed on the same entry. The convergence is not taste — it is built into how the candidates are ordered, how the reviewers talk, and what the deciding agent is allowed to see.

    Mechanism

    Six pressures, all pointing the same way.

    Ordered by how much each one contributes. The first two are sufficient on their own; the rest make the outcome near-certain.

    Primarydecides the pick

    The agent that makes the decision never sees the course.

    Deliberation.run() hands the summarizer the discussion transcript and nothing else — no course context, no chapter list, no inventory summaries, none of the best_for / avoid_for guidance the three reviewers were given.

    Its only view of the 46 candidates is the bare ALLOWED_STYLE_PAIRS list appended to its own output contract: source/key pairs, no descriptions, fixed order. When the transcript is mushy, it picks off that list.

    Structuralremoves dissent

    Three reviewers, but only one independent opinion.

    The deliberation runs max_rounds=1 with agents in fixed sequence, and each agent after the first receives the full transcript. The instruction reinforces it: "respond to earlier reviewers while adding your own comparison evidence."

    Teaching Faculty speaks first and unopposed. Instructional Designer and Course Coordinator then react to a position already on the table, and there is no second round in which anyone can revisit it. This is an information cascade, not a vote.

    Amplifierpicks the target

    The reviewer briefs are written in Blue Professional's own vocabulary.

    The three system prompts ask for accessible contrast, readable density, consistent information hierarchy, and respect for institutional context. Blue Professional's index entry reads: mood professional, modern, calm, trustworthy; tone clean, considered, polished, neutral; formality medium-high; scheme light.

    It is the nearest neighbour to the brief by construction. The instruction does tell agents that "merely being professional, clear, or engaging" is not adequate — but that constrains how they justify a pick, not which pick they reach for.

    src/html_slides_style.py:1162–1176reviewer system prompts
    Amplifierpenalizes character

    The avoid_for check rewards whichever style is least committal.

    The contract requires an avoid_for_assessment: state the selected entry's "Avoid for" warning, then explain why it does not conflict. Blue Professional's warning is "contexts where the deck should feel hot, playful, or intentionally informal" — trivially cleared for any university course.

    Every distinctive template carries a warning that is harder to argue past: Daisy Days is "not suitable for serious contexts", 8-Bit Orbit fails "quiet institutional" framing, Bold Poster cannot carry dense slides. The rule was written to add rigor. In practice it is a risk-minimizer that selects for blandness.

    Proposed fix

    Give the decision real inputs, then break the anchor.

    Ordered by leverage. The first two are small, contained changes and should move the distribution on their own; run those, re-measure, and only add the rest if it is still lopsided.

    Fix 01

    Let the summarizer see the brief.

    Add an opt-in context flag to Deliberation so the summary call can carry the instruction prompt — course name, chapters, foundation documents, and the full inventory with descriptions — instead of the transcript alone. Keep it opt-in so other deliberations keep their current token profile.

    Fix 02

    Shuffle candidate order per course, deterministically.

    Derive a seed from the course name so a given course still reproduces exactly, then shuffle the copy that goes into the prompt and into ALLOWED_STYLE_PAIRS. Leave inventory_hash computed over the canonical sorted list — it is the integrity fingerprint for frozen styles and must not move.

        Fix 05

        Require the shortlist to actually differ.

        The contract already demands 2–4 rejected alternatives, but nothing stops those from being three variations on the same neutral light template. Require the compared set to span at least two distinct scheme values (light / dark / mixed) and two distinct formality bands, and validate it in _validate_selection_evidence against the inventory metadata that is already loaded.

        Pair it with a softer avoid_for_assessment: keep the disclosure, drop its role as a tiebreak, and add an explicit line that a style must not be chosen solely because its warning is easy to clear.

        Fix 06

        Measure the distribution instead of trusting it.

        statistics_slide_style.json already records the selection per run. Add a check that reads every run under exp/ and fails when any single style exceeds a share threshold — 40% is a reasonable starting line for 46 candidates. That turns "the themes all look the same" into a number that regresses visibly.

        Also worth logging: which cause fired. Record the prompt-facing rank of the selected style alongside the pick, so a future collapse can be attributed to ordering or ruled out in one query.
